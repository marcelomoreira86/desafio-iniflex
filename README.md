# Desafio Iniflex - Gestão de Funcionários

Projeto em Java para gerenciamento de funcionários.

## 🚀 Tecnologias
- Java 17+
- Collections e Stream API
- BigDecimal e LocalDate

## 📁 Estrutura
- Pessoa.java
- Funcionario.java  
- Principal.java

## ▶️ Como executar
javac src/main/java/com/iniflex/*.java
java -cp src/main/java com.iniflex.Principal
